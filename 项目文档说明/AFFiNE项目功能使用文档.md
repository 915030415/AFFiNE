# AFFiNE 项目功能使用文档

## 📖 项目简介

### AFFiNE 是什么？

AFFiNE 是一个开源的 all-in-one 工作空间，旨在成为 Notion 和 Miro 的替代品。它将文档编辑、知识管理和无界画布功能融合在一个平台中，为用户提供完整的创作和协作体验。

### 🌟 核心特性

- **📝 双模式编辑器**：支持传统文档模式(Page)和无界画布模式(Edgeless)
- **🤖 AI 助手集成**：智能内容生成和编辑辅助
- **🔄 本地优先**：数据本地存储，支持离线工作和实时同步
- **👥 实时协作**：多人同时编辑，实时评论和反馈
- **🏠 自托管支持**：完全控制你的数据
- **🔓 开源透明**：代码完全开源，社区驱动开发

### 🏗️ 技术架构

**前端技术栈：**

- React + TypeScript
- Vite 构建工具
- BlockSuite 编辑器框架
- Jotai 状态管理
- CSS-in-JS (vanilla-extract)

**后端技术栈：**

- Node.js + NestJS
- GraphQL API
- SQLite/PostgreSQL 数据库
- WebSocket 实时通信

**移动端：**

- React Native
- iOS/Android 支持

## 🚀 快速开始

### 安装和部署

#### 开发环境要求

- Node.js 18+
- pnpm 8+
- Git

#### 本地开发

```bash
# 克隆项目
git clone https://github.com/toeverything/AFFiNE.git
cd AFFiNE

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

#### Docker 部署

```bash
# 使用 Docker Compose
docker-compose up -d
```

### 基本使用

1. **创建工作空间**：首次使用时创建你的工作空间
2. **新建页面**：使用 `⌘+N` (Mac) 或 `Ctrl+N` (Windows) 创建新页面
3. **模式切换**：在页面右上角切换 Page 和 Edgeless 模式
4. **快速搜索**：使用 `⌘+K` (Mac) 或 `Ctrl+K` (Windows) 打开全局搜索

## 🎯 核心功能详解

### 📄 页面编辑 (Page Mode)

#### 文本编辑

- **富文本支持**：粗体、斜体、下划线、删除线
- **标题层级**：支持 H1-H6 六级标题
- **列表功能**：有序列表、无序列表、任务列表
- **代码支持**：行内代码和代码块
- **链接插入**：超链接和页面内链接

#### 块元素

- **表格**：使用 `/table` 创建简单表格
- **数据库**：使用 `/database` 创建数据库视图
- **图片**：拖拽或粘贴插入图片
- **分割线**：使用 `***` 或 `/divider` 插入

### 🎨 无界画布 (Edgeless Mode)

#### 绘图工具 /frame

- **选择工具 (V)**：选择和移动元素
- **文本工具 (T)**：添加文本框
- **形状工具 (S)**：绘制几何图形
- **笔工具 (P)**：自由绘制
- **连接工具 (C)**：连接元素
- **抓手工具 (H)**：拖拽画布

#### 视图控制

- **缩放功能**：支持放大、缩小、适应屏幕
- **网格对齐**：精确定位元素
- **图层管理**：元素层级控制

### 📊 表格和数据库

#### 简单表格

- 使用 `/table` 命令创建
- 默认 2x2 结构，可动态调整
- 支持富文本内容

#### 数据库表格

- 使用 `/database` 命令创建
- 支持多种字段类型：文本、数字、日期、选择等
- 提供筛选、排序、分组功能
- 支持多种视图：表格、看板、日历

#### 数据导出

- **HTML 格式**：保持完整格式
- **Markdown 格式**：纯文本格式
- **CSV 格式**：Excel 兼容格式
- **PDF 格式**：打印友好格式
- 上传文件 /file 最大 10mb

### 🤖 AI 助手

#### AI 功能

- **智能写作**：内容生成和续写
- **文本优化**：语法检查和改进建议
- **翻译功能**：多语言翻译
- **摘要生成**：长文本摘要

#### 使用方式

- 选中文本后右键调用 AI 功能
- 使用 AI 聊天面板进行对话
- 空格键快速激活 AI 助手

### 👥 协作功能

#### 实时协作

- **多人编辑**：同时编辑同一文档
- **光标显示**：查看其他用户的编辑位置
- **冲突解决**：自动处理编辑冲突

#### 评论系统

- **页面评论**：在任意位置添加评论
- **回复功能**：评论串讨论
- **提及用户**：@用户名通知

#### 分享和权限

- **链接分享**：生成分享链接
- **权限控制**：查看、编辑、管理权限
- **私有链接**：团队内部分享

## 🔧 高级功能

### 📤 数据导入导出

#### 支持的导入格式

- **Markdown 文件** (.md)
- **HTML 文件** (.html)
- **图片文件** (PNG, JPG, GIF, SVG)
- **其他笔记应用数据**

#### 支持的导出格式

- **PDF**：完整页面布局，适合打印和分享
- **HTML**：保持格式的网页文件
- **Markdown**：纯文本格式，兼容其他编辑器
- **PNG**：图片格式，适合截图分享
- **CSV**：表格数据，Excel 兼容

#### 导出操作

1. 打开页面菜单（右上角三点图标）
2. 选择"导出"选项
3. 选择目标格式
4. 确认导出设置

### 🏢 工作空间管理

#### 工作空间功能

- **多工作空间支持**：为不同项目创建独立空间
- **成员管理**：邀请团队成员，设置权限
- **数据同步**：本地和云端数据同步
- **备份恢复**：定期备份，支持数据恢复

#### 工作空间设置

1. 点击左下角工作空间名称
2. 选择"工作空间设置"
3. 配置基本信息、成员权限、同步设置等

### 🔌 插件和扩展

#### 实验性功能

- **移动端键盘工具栏**：移动设备编辑增强
- **AI 功能增强**：更多 AI 辅助功能
- **第三方集成**：与其他服务的集成

#### 启用实验性功能

1. 进入设置 → 实验性功能
2. 选择要启用的功能
3. 重启应用生效

## 👨‍💻 开发者指南

### 📁 项目结构

```
AFFiNE/
├── packages/
│   ├── frontend/           # 前端代码
│   │   ├── core/          # 核心应用
│   │   ├── component/     # 共享组件
│   │   └── i18n/          # 国际化

│   └── common/            # 共享代码

├── tools/                 # 构建工具
└── tests/                 # 测试文件
```

### 🛠️ 开发环境搭建

#### 环境要求

- Node.js 18.0+
- pnpm 8.0+
- Git
- Docker (可选)

#### 安装步骤

```bash
# 1. 克隆仓库
git clone https://github.com/toeverything/AFFiNE.git
cd AFFiNE

# 2. 安装依赖
pnpm install

# 3. 构建项目
pnpm build

# 4. 启动开发服务器
pnpm dev
```

#### 常用开发命令

```bash
# 启动前端开发服务器
pnpm dev:web

# 启动后端服务器
pnpm dev:server

# 运行测试
pnpm test

# 代码格式化
pnpm format

# 类型检查
pnpm typecheck

# 构建生产版本
pnpm build
```

### 🤝 贡献指南

#### 贡献流程

1. Fork 项目到你的 GitHub 账户
2. 创建功能分支：`git checkout -b feature/your-feature`
3. 提交更改：`git commit -m 'Add some feature'`
4. 推送分支：`git push origin feature/your-feature`
5. 创建 Pull Request

#### 代码规范

- 使用 TypeScript
- 遵循 ESLint 规则
- 编写测试用例
- 更新相关文档

#### 提交信息规范

```
type(scope): description

[optional body]

[optional footer]
```

类型说明：

- `feat`: 新功能
- `fix`: 修复 bug
- `docs`: 文档更新
- `style`: 代码格式调整
- `refactor`: 代码重构
- `test`: 测试相关
- `chore`: 构建过程或辅助工具的变动
